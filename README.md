## 🚀 Sobre mí

Soy estudiante de **Ingeniería Informática en PUCP** con interés en **Data Engineering, Desarrollo Web Full Stack, Cloud Computing y Automatización**.

Me apasiona construir soluciones prácticas — desde pipelines de datos en la nube hasta webhooks serverless — y disfruto compartir conocimiento como **Jefe de Práctica de Fundamentos de Programación**.

---

## 💼 Experiencia y proyectos

- ☁️ **Data Engineering en AWS**: Diseño e implementación de un **Data Lake con arquitectura Medallion** (Bronze/Silver/Gold) sobre S3, con pipelines ETL en **PySpark sobre AWS Glue**, orquestación con **EventBridge**, consultas con **Athena** y dashboards en **AWS QuickSight**.
- 🔗 **Integración serverless**: Desarrollo de webhooks con **AWS Lambda + API Gateway**, incluyendo CI/CD automatizado con **GitHub Actions** y autenticación segura vía **OIDC (IAM Roles)** — sin uso de access keys.
- 📊 **Business Intelligence**: Reportes y dashboards con **Power BI** (DAX, Visual Calculations), conectados a **PostgreSQL (RDS Aurora)** vía ODBC/VPN.
- 🗄️ **Optimización de SQL**: Mejora de queries complejas sobre bases de datos PostgreSQL — reemplazando funciones recursivas por CTEs pre-calculadas, reduciendo tiempos de ejecución de horas a minutos.
- 💻 **Desarrollo Web Full Stack**: Aplicaciones con **React**, **ASP.NET**, **Node.js** y backends en **Java y C#**. Integración con **Strapi** (headless CMS).
- ⚙️ **Automatización de Procesos**: Flujos con **n8n** y **Power Automate** para integración empresarial.
- 🎓 **Docencia**: Jefe de Práctica en **Fundamentos de Programación** en PUCP.
