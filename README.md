## 🚀 Sobre mí
Soy un estudiante de **Ingeniería Informática en PUCP** con interés en **Inteligencia de Negocios, Desarrollo Web y Cloud Computing (AWS)**.  
Me apasiona transformar datos en conocimiento y construir soluciones prácticas que unan el análisis con el desarrollo tecnológico.  

## 💼 Experiencia y proyectos
- 📊 **Inteligencia de Negocios**: Desarrollo de reportes y dashboards con **SQL, Power BI y Python**, aplicados a transacciones y métricas de negocio.  
- 💻 **Desarrollo Web**: Creación de sistemas CRUD y de gestión (reservas, clínicas, catálogos) con **Node.js, C#, Java y tecnologías web**.  
- ☁️ **Cloud (AWS)**: Uso de **Rekognition** para análisis de imágenes, **RDS** para bases de datos relacionales en la nube y **DynamoDB** para soluciones NoSQL escalables.
